My MEng thesis, [*Model Merging and Task Overfitting in Speech LLMs*](https://github.com/ebinezer-rajaram/speech-llm-merging), showed that LoRA adapters in a 3B Speech LLM quietly break each other's tasks, and that calibrated layer-wise merging recovers single-task performance on average without joint retraining, using 16× less training data than multi-task training.
