#### Featured research

**[Model Merging and Task Overfitting in Speech LLMs](https://github.com/ebinezer-rajaram/speech-llm-merging)** · MEng thesis
LoRA adapters for a 3B Speech LLM look modular but quietly break each other's tasks. I measured that interference across 7 speech tasks and showed that calibrated layer-wise merging recovers single-task performance on average, with better worst-task balance than joint multi-task training while using 16× fewer training examples.
